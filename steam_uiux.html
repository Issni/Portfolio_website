A Conceptual Redesign of the Steam Mobile Application

Role UI / UX Designer
Tools Figma
Type Conceptual Redesign
01

About Project

As someone who grew up on gaming, I found the Steam mobile experience consistently frustrating. The app lacks the visual polish and navigation clarity of the desktop client — browsing libraries, checking store pages, and managing downloads all feel like afterthoughts on mobile.

This project is a full conceptual redesign of the Steam mobile app, focused on bringing the desktop experience to mobile with better hierarchy, faster navigation, and a visual language true to the Steam brand.

02

Problem Statement

One of the main issues I noticed was the inconsistency of the interface, and how icons used across the Steam app felt foreign and out of place. The app's information density is high but the hierarchy is flat — everything competes for attention equally.

Navigation between the Store, Library, Community, and Profile requires too many taps. Discovery is buried. Key actions like downloading, purchasing, and adding to wishlist are not surfaced consistently.

03

Possible Solution

My goal is to create a cleaner, more organised interface of high quality. The redesign aims to establish a consistent visual language, a bottom navigation rail for one-thumb reachability, and a card-based layout that surfaces the most relevant content per section.

Priority actions — download progress, store deals, friend activity — are all surfaced one tap from the home screen. Typography scales and spacing follow a strict grid to ensure readability across device sizes.
